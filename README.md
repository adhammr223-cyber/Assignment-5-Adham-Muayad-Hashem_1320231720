# TechLaunch — صفحة هبوط

## التقنيات

HTML وCSS.

## فكرة المشروع

عرض صفحة هبوط مع صورة رئيسية وبطاقات وتنسيق مستقل في landing.css.

## التشغيل

1. نزّل المستودع أو انسخه.
2. افتح `index.html` في متصفح حديث.
3. احتفظ بمجلدات الصور والملفات في مواقعها الحالية حتى تعمل المسارات.

## ملفات البداية

- `index.html`
- `landing.css`

## حدود المشروع

الواجهة للتدريب؛ أي دعوات للتسجيل لا تمثّل خدمة حسابات فعلية.
