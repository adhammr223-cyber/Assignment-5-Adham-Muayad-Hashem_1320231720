# TechLaunch Landing Page

A landing page with a hero section, cards and a separate CSS stylesheet.

## Technologies

HTML, CSS.

## Run locally

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Keep the existing image and stylesheet folders in place.

## Project scope

The page is a design exercise; sign-up links do not provide an account service.
